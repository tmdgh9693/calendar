관리자 전용

HWPX 서식 초안 설정

회의자료와 출장복명서용 HWPX 파일을 등록하고 선택할 수 있습니다. 다만 임의의 HWPX가 모두 호환되는 것은 아니며, 현재 기본 양식과 같은 표 구조 또는 지원되는 치환 표시값이 있는 파일만 정상 생성됩니다. 출장복명서 양식은 사진대지 표 구조가 있어야 사진을 삽입할 수 있습니다.

파일을 고른 뒤 선택한 파일 등록을 누르세요. 등록 직후 현재 용도의 사용 템플릿으로 자동 선택됩니다.

백업·복원

선택한 기간의 과 캘린더 일정, 회의자료, 출장복명서만 백업합니다. 개인 캘린더, 사진 보관함, 사용자 설정과 출장복명 임시저장은 제외됩니다.

포함: 과 캘린더 일정 · 회의자료 · 출장복명서
제외: 개인 캘린더 · 사진 보관함 백업 · 사용자 설정 · 출장복명 임시저장

백업본 불러오기 (관리자 전용)

이 프로그램에서 만든 .zip 백업 파일을 선택하면 과 캘린더 일정, 회의자료와 출장복명서를 다시 불러옵니다. ZIP은 압축을 풀지 않고 그대로 선택하세요.

웹앱 다운로드

설치하면 브라우저 주소 입력 없이 홈 화면에서 바로 실행할 수 있습니다. Android/PC는 버튼을 누르고, iPhone/iPad는 Safari 공유 버튼 → 홈 화면에 추가를 선택하세요.

사진 보관함

사진을 올리면 원본과 자동 압축본이 저장됩니다. 같은 계정으로 로그인한 휴대폰과 컴퓨터에서 함께 표시하고 다운로드할 수 있습니다.

원본은 여러 조각으로 나누고, 압축본은 미리보기용으로 저장합니다. 기존에 압축본만 저장된 사진은 카드의 “원본 다시 연결”에서 원본 파일을 선택하면 이후 모든 기기에서 원본 다운로드가 가능합니다. 사진 한 장당 원본은 15MB 이하만 올릴 수 있습니다.

사진 다운로드·삭제 여러 장은 ZIP 파일 한 개로 내려받습니다.
